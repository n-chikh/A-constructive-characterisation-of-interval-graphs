# A Constructive Characterisation of Interval Graphs

This repository stores the Python modules containing the implementation of many results of a forthcoming paper titled *"A constructive characterisation of interval graphs"*.

Each module in [main/src](https://github.com/n-chikh/A-constructive-characterisation-of-interval-graphs/tree/main/src).

The preprint proposes a generalisation of threshold graphs and proves that the resulting class is that of interval graphs.
