# A constructive Characterisation of Interval Graphs

This repository stores the Python modules accompanying a forthcoming paper titled *"A constructive characterisation of interval graphs"*.

We introduce a procedure that generalises that of threshold graphs. We prove that the procedure characterises interval graphs. This repository contains the implementation of this procedure and the subsequent results.

Each module in [main/src](https://github.com/n-chikh/A-constructive-characterisation-of-interval-graphs/tree/main/src) implement one particular result in the preprint.
